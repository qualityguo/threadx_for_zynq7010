## 多核 SMP 启动流程重构方案

### 一、重构目标

1. **栈指针动态计算**：用链接脚本导出的总栈大小 `/2` 替代硬编码的 per-core 常量
2. **主核 GIC/Timer C 化**：将 `tx_initialize_low_level.S` 中 CPU0 的 GIC + Private Timer + SGI 0 配置迁移到 `bsp_init()` 的 BSP C 库函数
3. **从核 GIC 保留汇编**：CPU1 的 GIC CPU Interface + SGI 0 保留汇编实现（通过 CP15 取址，避免 `xInterruptController` 竞态）
4. **补全从核性能优化**：CPU1 补充分支预测和预取配置

### 二、重构范围

| 修改项 | CPU0（主核） | CPU1（从核） |
|--------|:---:|:---:|
| GIC Distributor 使能 | `bsp_init()` → C（`XScuGic_CfgInitialize` 已覆盖） | 不需要 |
| GIC CPU Interface | `bsp_init()` → C（已覆盖） | **保留汇编** |
| Priority Mask 0xF0 | `bsp_init()` → C（已覆盖） | **保留汇编** |
| Private Timer (ID 29) 使能 + 启动 | `bsp_init()` → C（`XScuTimer_*`） | 不需要 |
| SGI 0 (核间中断) | `bsp_init()` → C（`XScuGic_Enable(0)`） | **保留汇编** |
| 栈指针计算 | 改为 `total_size / 2` 动态计算 | 同左 |
| 分支预测 + 预取 | 已有（`primaryCPUInit`） | **补全**（`secondaryCPUsInit`） |
| `tx_initialize_low_level.S` | 精简为仅 CPU ID 检查 + unused memory | 不涉及 |

### 三、竞态分析：为什么 CPU1 的 GIC 必须保留汇编

#### 时序图

```
CPU0: primaryCPUInit
        ├─ SCU + L2 初始化
        ├─ 使能 caches
        ├─ 写 0xFFFFFFF0 = _vector_table
        ├─ Clean + DSB + SEV  ───────────── CPU1 被唤醒
        └─ B _start                       │
            ├─ 清零 BSS                    │
            ├─ 全局构造函数                │
            └─ main()                      │    CPU1: Reset_Handler
                ├─ bsp_init()              │      ├─ joinSMP
                │   ├─ Global_Timer_Init() │      ├─ 设栈/MMU/VFP
                │   ├─ GIC_Init()          │      │  (纯寄存器操作，极快)
                │   │  XScuGic_CfgInitialize│      ├─ CPU ID check
                │   │  填充 xInterruptController     └─ secondaryCPUsInit
                │   ├─ XScuTimer_*          │           ├─ enableCaches
                │   └─ XScuGic_Enable()     │           └─ GIC 汇编调用
                └─ board_init()             │              (MRC p15 取址)
                   ...                      │              ↑ 无竞态！
```

#### 核心问题

若 CPU1 的 GIC 也用 C 函数（`bsp_init_secondary()`），则依赖 `xInterruptController.CpuBaseAddress`。
该字段由 CPU0 的 `XScuGic_CfgInitialize()` 填充。CPU1 路径全是寄存器操作（极快），
CPU0 路径含 BSS 清零 + C 运行时初始化 + 多层函数调用（较慢），**CPU1 很可能先到达**，
此时 `xInterruptController` 尚未初始化 → 写入非法地址 → 系统崩溃。

#### 汇编为何安全

```asm
@ MP_GIC.S: enableGICProcessorInterface
    MRC     p15, 4, r0, c15, c0, 0   @ 直接从 CP15 读取外设基地址
    LDR     r1, [r0, #0x100]         @ 直接操作硬件寄存器
    ...
```

- 通过 `MRC p15` 获取 GIC 基地址，**不依赖任何 C 全局变量**
- 不存在与 CPU0 的 `xInterruptController` 初始化之间的竞态
- 无论是 JTAG 调试启动还是 QSPI Flash 固化启动，均安全

### 四、具体修改

#### 1. 修改 `startup.S`

##### 1.1 栈指针计算：硬编码 → 动态计算

**删除**头部的硬编码常量：

```asm
@ 删除以下常量定义：
@ SYS_STACK_PER_CORE   =  0x1000
@ IRQ_STACK_PER_CORE   =  0x0800
@ SVC_STACK_PER_CORE   =  0x1000
```

**修改** `Reset_Handler` 中栈设置代码段（原 `startup.S:235-261`）：

```asm
@ r0 = CPU ID (0 或 1，已在前面读出)

@ ---- IRQ 栈 ----
    MOV     r1, #IRQ_MODE
    MSR     CPSR_c, r1
    LDR     r1, =__irq_stack
    LDR     r3, =_IRQ_STACK_SIZE              @ 链接脚本总量 0x1000
    LSR     r3, r3, #1                         @ per_core = total / 2
    MUL     r3, r0, r3                         @ offset = CPU_ID * per_core
    SUB     sp, r1, r3

@ ---- SVC 栈 ----
    MOV     r1, #SVC_MODE
    MSR     CPSR_c, r1
    LDR     r1, =__supervisor_stack
    LDR     r3, =_SUPERVISOR_STACK_SIZE        @ 0x2000
    LSR     r3, r3, #1
    MUL     r3, r0, r3
    SUB     sp, r1, r3

@ ---- ABT 栈 ----
    MOV     r1, #ABT_MODE
    MSR     CPSR_c, r1
    LDR     r1, =__abort_stack
    MOV     sp, r1                             @ 共享，不按核偏移

@ ---- FIQ 栈 ----
    MOV     r1, #FIQ_MODE
    MSR     CPSR_c, r1
    LDR     r1, =__fiq_stack
    MOV     sp, r1                             @ 共享，不按核偏移

@ ---- SYS 栈 ----
    MOV     r1, #SYS_MODE
    MSR     CPSR_c, r1
    LDR     r1, =__stack
    LDR     r3, =_STACK_SIZE                   @ 0x2000
    LSR     r3, r3, #1
    MUL     r3, r0, r3
    SUB     sp, r1, r3

@ ---- 切回 SVC 模式 ----
    MOV     r1, #SVC_MODE
    MSR     CPSR_c, r1
```

**原理**：链接脚本 `_IRQ_STACK_SIZE` 等是 `ld` 的绝对符号，
`LDR r3, =_IRQ_STACK_SIZE` 通过 literal pool 加载其值（0x1000），
无需解引用。`LSR #1` 实现 `/2`，`MUL` 计算 CPU_ID × per_core 偏移。
修改链接脚本中的栈大小后，汇编自动适配，不再需要同步维护两处常量。

##### 1.2 `secondaryCPUsInit`：补全分支预测 + 保留汇编 GIC

```asm
secondaryCPUsInit:

@  ; GIC CPU Interface（保留汇编，通过 CP15 取址，无竞态风险）
    BL      enableGICProcessorInterface

    MOV     r0, #0xF0                 @ Priority mask
    BL      setPriorityMask

@  ; Enable SGI for inter-core interrupts
    MOV     r0, #0                     @ SGI ID 0
    BL      enableIntID

    MOV     r0, #0                     @ SGI ID 0
    MOV     r1, #0                    @ Priority
    BL      setIntPriority

@  ; Enable caches
    BL      enableCaches

@  ; 补全：分支预测（当前代码缺失，CPU1 未使能 Z bit）
    MRC     p15, 0, r0, c1, c0, 0
    ORR     r0, r0, #(0x1 << 11)              @ SCTLR.Z: 分支预测
    MCR     p15, 0, r0, c1, c0, 0

@  ; 补全：D-side 预取 + L2 预取提示
    MRC     p15, 0, r0, c1, c0, 1             @ ACTLR
    ORR     r0, r0, #(0x1 << 2)               @ D-side prefetch
    ORR     r0, r0, #(0x1 << 1)               @ L2 prefetch hint
    MCR     p15, 0, r0, c1, c0, 1

@  ; Branch to ThreadX SMP wait loop
    B       _tx_thread_smp_initialize_wait
```

**与原代码的差异**：
- 删除了 `enableCaches` 之后直接跳转的方式，改为先使能 caches 再补充分支预测和预取
- GIC 配置保留汇编不变
- 新增分支预测 + 预取，与 CPU0 的 `primaryCPUInit` 保持一致

#### 2. 修改 `bsp_init.c`

```c
#include "bsp_init.h"
#include "xparameters.h"
#include "xscugic.h"
#include "xscutimer.h"

#define GTIMER_COUNTER_LO   (*(volatile u32 *)0xF8F00200)
#define GTIMER_COUNTER_HI   (*(volatile u32 *)0xF8F00204)
#define GTIMER_CONTROL      (*(volatile u32 *)0xF8F00208)

XScuGic xInterruptController;
static XScuTimer xScuTimer;

static void Global_Timer_Init()
{
    GTIMER_CONTROL    = 0x00;
    GTIMER_COUNTER_LO = 0;
    GTIMER_COUNTER_HI = 0;
    GTIMER_CONTROL    = 0x01;
}

static void GIC_Init()
{
    XScuGic_Config *intc_cfg;
    intc_cfg = XScuGic_LookupConfig(INTC_DEVICE_ID);
    XScuGic_CfgInitialize(&xInterruptController, intc_cfg,
                          intc_cfg->CpuBaseAddress);
}

static void PrivateTimer_Init(void)
{
    XScuTimer_Config *cfg = XScuTimer_LookupConfig(XPAR_XSCUTIMER_0_DEVICE_ID);
    XScuTimer_CfgInitialize(&xScuTimer, cfg, cfg->BaseAddr);
    XScuTimer_LoadTimer(&xScuTimer, 3333333);
    XScuTimer_EnableAutoReload(&xScuTimer);
    XScuTimer_EnableInterrupt(&xScuTimer);
    XScuTimer_Start(&xScuTimer);
}

void tx_irq_dispatch(unsigned int int_id)
{
    extern XScuGic xInterruptController;

    if (int_id < XSCUGIC_MAX_NUM_INTR_INPUTS)
    {
        XScuGic_VectorTableEntry *entry =
            &xInterruptController.Config->HandlerTable[int_id];
        entry->Handler(entry->CallBackRef);
    }
}

void bsp_init()
{
    Global_Timer_Init();
    GIC_Init();

    /* 原 tx_initialize_low_level.S 步骤: Private Timer 中断 (ID 29) */
    XScuGic_SetPriorityTriggerType(&xInterruptController, 29, 0, 0);
    XScuGic_Enable(&xInterruptController, 29);

    /* 原 tx_initialize_low_level.S 步骤: Private Timer 初始化 + 启动 */
    PrivateTimer_Init();

    /* 原 tx_initialize_low_level.S 步骤: SGI 0 (核间中断) */
    XScuGic_SetPriorityTriggerType(&xInterruptController, 0, 0, 0);
    XScuGic_Enable(&xInterruptController, 0);
}
```

#### 3. 修改 `bsp_init.h`

增加 `xscutimer.h` 头文件引用（若 `bsp_init.h` 中需要导出类型）。

#### 4. 精简 `tx_initialize_low_level.S`

```asm
@/***************************************************************************
@ * ThreadX SMP Low-Level Initialization for Zynq 7010 (Cortex-A9 MPCore)
@ *
@ * Called from tx_kernel_enter() on core 0 only.
@ * GIC and Timer initialization has been moved to bsp_init() (C code).
@ **************************************************************************/

@; ------------------------------------------------------------
@; Imports
@; ------------------------------------------------------------
    .global      _tx_thread_system_stack_ptr
    .global      _tx_initialize_unused_memory
    .global      _tx_version_id
    .global      _tx_build_options
    .global      _end

    .arm
    .text
    .align 2

@/**************************************************************************/
    .global _tx_initialize_low_level
    .type _tx_initialize_low_level,function
_tx_initialize_low_level:

    PUSH    {lr}

    @; ---- Sanity check: this function must only be called on core 0 ----
    MRC     p15, 0, r0, c0, c0, 5
    AND     r0, r0, #0x03
    CMP     r0, #0
    BNE     _low_level_panic

    @; ---- Save unused memory pointer ----
    LDR     r0, =_end
    LDR     r2, =_tx_initialize_unused_memory
    ADD     r0, r0, #8
    STR     r0, [r2]

    B       _low_level_done

_low_level_panic:
    WFE
    B       _low_level_panic

_low_level_done:
    POP     {lr}
    BX      lr

BUILD_OPTIONS:
    .word  _tx_build_options
VERSION_ID:
    .word  _tx_version_id
```

**删除的 import**：
```asm
@ .global enableGIC
@ .global enableGICProcessorInterface
@ .global setPriorityMask
@ .global enableIntID
@ .global setIntPriority
@ .global init_private_timer
@ .global start_private_timer
```

### 五、寄存器操作与 BSP 库函数映射（CPU0 部分）

| 原 `tx_initialize_low_level.S` 步骤 | 汇编调用 | BSP 替代函数（`bsp_init()` 中） | 说明 |
|---|---|---|---|
| GIC Distributor 使能 | `enableGIC()` | `XScuGic_CfgInitialize()` 已覆盖 | ICDDCR bit0 |
| GIC CPU Interface 使能 | `enableGICProcessorInterface()` | `XScuGic_CfgInitialize()` 已覆盖 | ICCICR = 0x07 |
| 优先级掩码 | `setPriorityMask(0xF0)` | `XScuGic_CfgInitialize()` 已覆盖 | ICCPMR = 0xF0 |
| Timer 中断使能 | `enableIntID(29)` | `XScuGic_Enable(&xInterruptController, 29)` | ICDISER |
| Timer 中断优先级 | `setIntPriority(29, 0)` | `XScuGic_SetPriorityTriggerType(..., 29, 0, 0)` | ICDIPR |
| Timer 初始化 | `init_private_timer(3333333, 0)` | `XScuTimer_LoadTimer` + `EnableAutoReload` + `EnableInterrupt` | Private Timer |
| Timer 启动 | `start_private_timer()` | `XScuTimer_Start()` | Private Timer |
| SGI 0 使能 | `enableIntID(0)` | `XScuGic_Enable(&xInterruptController, 0)` | ICDISER |
| SGI 0 优先级 | `setIntPriority(0, 0)` | `XScuGic_SetPriorityTriggerType(..., 0, 0, 0)` | ICDIPR |
| 空闲内存保存 | `_end + 8 → _tx_initialize_unused_memory` | **保留在汇编中** | 纯符号操作 |

### 六、CPU1 的 GIC 配置：保留汇编的理由

| 考量 | 分析 |
|------|------|
| 竞态安全 | 通过 `MRC p15` 取 GIC 基地址，不依赖 `xInterruptController` C 全局变量 |
| Flash 启动 | BSS 可能尚未清零，`xInterruptController.CpuBaseAddress` 值未定义 |
| JTAG 启动 | CPU1 可能先于 CPU0 的 `GIC_Init()` 到达，同样存在竞态 |
| 代码量 | 仅 4 条 `BL` 调用，封装为 C 函数收益极小 |
| 可维护性 | 汇编函数语义清晰（函数名自解释），无额外维护负担 |

### 七、重构后的完整启动流程

```
Reset_Handler:                         ← 两核共同路径（CPU1 从 Boot ROM WFE 唤醒后也走这里）
  ├─ joinSMP (设 ACTLR.SMP)
  ├─ 关闭 Cache / MMU / 分支预测
  ├─ 读 CPU ID → r0
  ├─ 设置各模式栈指针（size/2 动态计算）
  │    CPU0: sp = __xxx_stack - 0 * per_core = 栈顶
  │    CPU1: sp = __xxx_stack - 1 * per_core = 栈中部
  ├─ 切换 SVC 模式
  ├─ 设 VBAR = _vector_table
  ├─ 无效化 Cache / TLB
  ├─ 设域访问权限 0x55555555
  ├─ 设 TTB0 = MMUTable
  ├─ 使能 MMU + VFP
  ├─ 清零 _tx_thread_smp_release_cores_flag
  └─ CPU ID 分流
       │
       ├─ CPU0 → primaryCPUInit
       │    ├─ 使能 SCU + 维护广播
       │    ├─ 无效化 SCU Tag RAM (CPU0+CPU1)
       │    ├─ L2 Cache 初始化 + 使能
       │    ├─ 使能 Caches + 分支预测 + 预取
       │    ├─ 启动 CPU1 (写 0xFFFFFFF0 + Clean + DSB + SEV)
       │    └─ B _start
       │         ├─ C 运行时 (_start)
       │         │    ├─ 清零 BSS
       │         │    └─ 全局构造函数
       │         └─ main()
       │              ├─ bsp_init()  ← 重构重点
       │              │    ├─ Global_Timer_Init()
       │              │    ├─ GIC_Init()
       │              │    │    └─ XScuGic_CfgInitialize()  ← 覆盖原步骤 1-3
       │              │    ├─ XScuGic_SetPriorityTriggerType(29, 0, 0)  ← 原步骤 4a
       │              │    ├─ XScuGic_Enable(29)                        ← 原步骤 4b
       │              │    ├─ PrivateTimer_Init()                       ← 原步骤 5
       │              │    ├─ XScuGic_SetPriorityTriggerType(0, 0, 0)   ← 原步骤 6a
       │              │    └─ XScuGic_Enable(0)                         ← 原步骤 6b
       │              ├─ board_init()
       │              └─ tx_kernel_enter()
       │                   ├─ _tx_initialize_low_level()
       │                   │    ├─ CPU ID 检查 (仅 CPU0 可进入)
       │                   │    └─ 保存 _tx_initialize_unused_memory
       │                   ├─ tx_application_define()
       │                   ├─ 设置 _tx_thread_smp_release_cores_flag
       │                   └─ tx_thread_schedule()
       │                        └─ CPSIE i → AppTaskStart
       │
       └─ CPU1 → secondaryCPUsInit
            ├─ enableGICProcessorInterface  (汇编, MRC p15)
            ├─ setPriorityMask(0xF0)        (汇编, MRC p15)
            ├─ enableIntID(0)               (汇编, MRC p15)
            ├─ setIntPriority(0, 0)         (汇编, MRC p15)
            ├─ enableCaches
            ├─ 补全: 分支预测 + 预取
            └─ B _tx_thread_smp_initialize_wait
                 ├─ 等待 system_state == TX_INITIALIZE_IN_PROGRESS
                 ├─ 等待 release_cores_flag != 0
                 ├─ 等待 CPU0 的 system_state == 0
                 └─ B _tx_thread_schedule → 调度循环
```

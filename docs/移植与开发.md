## 第三章：参考设计

- 任务栈

  - 栈的空间采用静态分配

  - TCB中存储栈的一些信息，可以得到最大栈使用

    - ```c
      tx_thread_stack_end				// 栈底
      tx_thread_stack_ptr				// 实时栈顶
      tx_thread_stack_highest_ptr		// 最大栈顶
      ```

  - 栈检测使能

    - ```c
      // 使能栈填充
      #define TX_ENABLE_STACK_CHECKING
      // 注册栈出错回调函数
      tx_thread_stack_error_notify(my_stack_error_handler);
      // 回调函数中-可以停止并打印栈信息
      ```

- 任务优先级

  - 值越大，优先级越低，默认是0-31
  - 分配（优先级由高到低）
    - IRQ任务（阻塞实现）：中断服务函数中触发的任务
    - 高优先级后台任务（阻塞实现）：比如串口消息处理
    - 低优先级时间片调度任务：比如GUI显示
    - 空闲任务（设置了WFI，不需要）

- 空闲任务

  - 空闲任务中可以休眠、停机等降低CPU使用率
  - 但是这个项目中，我们在调度器的汇编代码中加入了`WFI`指令，不需要手动空闲任务了

- 任务调度

  - 抢占式调度：高优先级的就绪任务
  - 时间片调度：同优先级，时间片用完则调度
  - 轮询调度：很少使用

- 临界区

  - 中断锁：开关中断实现
  - 任务锁：ThreadX有抢占阈值，uCOS给调度器加锁，RTX关闭内核定时器
  - 调度锁：禁止调度，但不是不禁止中断
  - ThreadX的抢占阈值
    - 例如任务优先级是20，设置抢占阈值是15，则只有优先级为0-14的任务可以抢占

- 消息队列

  - ThreadX、RTX5、FreeRTOS消息队列传递了数据
  - RTX4、uCOSII和uCOSIII消息队列传递了地址

- 内存块和内存池

  - 内存块计算：每个内存块多占据一个指针的大小

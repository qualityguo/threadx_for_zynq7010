## 单核启动流程重构方案：将汇编 GIC/Timer 初始化迁移至 BSP C 函数

### 一、背景

当前单核版本（`hello_threadx`）的启动流程中，GIC 和 Private Timer 的初始化分散在两处：

1. **`bsp_init()`**（C 层）：调用 `XScuGic_CfgInitialize()` 初始化 GIC
2. **`tx_initialize_low_level.S`**（汇编层）：再次使能 GIC、设置优先级掩码、使能中断 ID、配置并启动 Private Timer

其中步骤 1 已经覆盖了步骤 2 中的 GIC Distributor 使能、CPU Interface 使能、优先级掩码设置（0xF0），存在重复初始化。

### 二、现有流程分析

#### 第四阶段 `tx_initialize_low_level.S` 的 9 个步骤

| 步骤 | 操作 | 汇编调用 |
|------|------|----------|
| 1 | 切换到 SVC 模式 | `MOV r0, #SVC_MODE; MSR CPSR_c, r0` |
| 2 | 保存系统栈指针 | `STR sp, [_tx_thread_system_stack_ptr]` |
| 3 | 记录空闲内存地址 | `_end + 8 → _tx_initialize_unused_memory` |
| 4 | 设置 VBAR + 禁用高向量 | `MCR p15, 0, r0, c12, c0, 0; BL disableHighVecs` |
| 5 | 使能 GIC Distributor + CPU Interface | `BL enableGIC; BL enableGICProcessorInterface` |
| 6 | 设置中断优先级掩码 | `BL setPriorityMask(0xF0)` |
| 7 | 使能 Private Timer 中断 + 设置优先级 | `BL enableIntID(29); BL setIntPriority(29, 0)` |
| 8 | 初始化并启动 Private Timer | `BL init_private_timer(3333333, 0); BL start_private_timer` |
| 9 | 使能 SGI 0 中断 | `BL enableIntID(0); BL setIntPriority(0, 0)` |

#### 步骤 5/6 与 `bsp_init()` 的重复

`XScuGic_CfgInitialize()` 内部已完成：
- 使能 GIC Distributor（写 `ICDDCR` 的 bit0）— 等价 `enableGIC()`
- 使能 CPU Interface（写 `ICCICR = 0x07`）— 等价 `enableGICProcessorInterface()`
- 设置 Priority Mask = 0xF0（写 `ICCPMR`）— 等价 `setPriorityMask(0xF0)`

#### 步骤 9 单核不需要

SGI（Software Generated Interrupt）ID=0 用于核间通信，单核版本可去掉。

### 三、重构方案

#### 核心思路

- **步骤 1-4**：必须保留在汇编中（涉及处理器模式切换、CP15 操作），不可用 C 替代
- **步骤 5-6**：已被 `XScuGic_CfgInitialize()` 覆盖，直接从汇编中删除
- **步骤 7-8**：用 BSP 库函数（`XScuGic_*` + `XScuTimer_*`）实现，集成到 `bsp_init()`
- **步骤 9**：单核不需要，直接删除

#### 寄存器操作与 BSP 库函数映射

| 步骤 | 原汇编调用 | BSP 替代函数 |
|------|-----------|-------------|
| 5 | `enableGIC()` + `enableGICProcessorInterface()` | 已被 `XScuGic_CfgInitialize()` 覆盖 |
| 6 | `setPriorityMask(0xF0)` | 已被 `XScuGic_CfgInitialize()` 覆盖 |
| 7a | `enableIntID(29)` | `XScuGic_Enable(&xInterruptController, 29)` |
| 7b | `setIntPriority(29, 0)` | `XScuGic_SetPriorityTriggerType(&xInterruptController, 29, 0, 0)` |
| 8a | `init_private_timer(3333333, 0)` | `XScuTimer_LoadTimer()` + `XScuTimer_EnableAutoReload()` + `XScuTimer_EnableInterrupt()` |
| 8b | `start_private_timer()` | `XScuTimer_Start()` |
| 9 | `enableIntID(0)` + `setIntPriority(0, 0)` | 单核不需要，去掉 |

#### 时序安全性分析

将 Private Timer 提前到 `bsp_init()` 中启动是安全的：

1. `boot.S` 和 C 运行时全程保持 **IRQ 禁止**（CPSR.I=1）
2. `tx_initialize_low_level.S` 中 `CPSIE i` 已被注释掉
3. Timer 中断会 pend 在 GIC 中，直到 `tx_thread_schedule()` 首次使能 IRQ 时才被响应
4. 此时 VBAR 已被 `tx_initialize_low_level` 切换到 ThreadX 的 `__vectors`，`__tx_irq_handler` → `tx_irq_dispatch()` → XScuGic HandlerTable 的分发链路完整

### 四、具体修改

#### 1. 修改 `bsp_init.c`

```c
#include "bsp_init.h"
#include "xparameters.h"
#include "xscutimer.h"              // 新增

XScuGic xInterruptController;
static XScuTimer xScuTimer;         // 新增

#define GTIMER_COUNTER_LO   (*(volatile u32 *)0xF8F00200)
#define GTIMER_COUNTER_HI   (*(volatile u32 *)0xF8F00204)
#define GTIMER_CONTROL      (*(volatile u32 *)0xF8F00208)

static void Global_Timer_Init()
{
    GTIMER_CONTROL    = 0x00;
    GTIMER_COUNTER_LO = 0;
    GTIMER_COUNTER_HI = 0;
    GTIMER_CONTROL    = 0x01;
}

static void GIC_Init()
{
    XScuGic_Config *intc_cfg;
    intc_cfg = XScuGic_LookupConfig(INTC_DEVICE_ID);
    XScuGic_CfgInitialize(&xInterruptController, intc_cfg, intc_cfg->CpuBaseAddress);
}

/* 新增：Private Timer 初始化（替代汇编 MP_PrivateTimer.S） */
static void PrivateTimer_Init(void)
{
    XScuTimer_Config *cfg = XScuTimer_LookupConfig(XPAR_XSCUTIMER_0_DEVICE_ID);
    XScuTimer_CfgInitialize(&xScuTimer, cfg, cfg->BaseAddr);

    XScuTimer_LoadTimer(&xScuTimer, 3333333);          // ~10ms @ 333MHz
    XScuTimer_EnableAutoReload(&xScuTimer);
    XScuTimer_EnableInterrupt(&xScuTimer);
    XScuTimer_Start(&xScuTimer);
}

void tx_irq_dispatch(unsigned int int_id)
{
    extern XScuGic xInterruptController;

    if(int_id < XSCUGIC_MAX_NUM_INTR_INPUTS)
    {
        XScuGic_VectorTableEntry * entry =
            &xInterruptController.Config->HandlerTable[int_id];
        entry->Handler(entry->CallBackRef);
    }
}

void bsp_init()
{
    Global_Timer_Init();
    GIC_Init();

    /* 原步骤 7：配置 Private Timer 中断（替代汇编 MP_GIC.S） */
    XScuGic_SetPriorityTriggerType(&xInterruptController, 29, 0, 0);
    XScuGic_Enable(&xInterruptController, 29);

    /* 原步骤 8：初始化并启动 Private Timer（替代汇编 MP_PrivateTimer.S） */
    PrivateTimer_Init();
}
```

#### 2. 精简 `tx_initialize_low_level.S`

只保留步骤 1-4，删除步骤 5-9 的所有 `BL` 调用和相关代码：

```asm
_tx_initialize_low_level:

    /* 保存 lr（进入时的模式） */
    MOV     r12, lr

    /* 步骤 1-2: 切换到 SVC 模式 + 保存系统栈指针 */
    MOV     r0, #SVC_MODE
    MSR     CPSR_c, r0
    LDR     r2, =_tx_thread_system_stack_ptr
    STR     sp, [r2]

    /* 步骤 3: 记录空闲内存 */
    LDR     r1, =_end
    LDR     r2, =_tx_initialize_unused_memory
    ADD     r1, r1, #8
    STR     r1, [r2]

    /* 步骤 4: 设置 VBAR + 禁用高向量 */
    LDR     r0, =__vectors
    MCR     p15, 0, r0, c12, c0, 0
    BL      disableHighVecs

    /*
     * 步骤 5-9 已迁移到 bsp_init() 中用 BSP C 库函数实现：
     *   步骤 5-6: XScuGic_CfgInitialize() 已覆盖
     *   步骤 7:   XScuGic_SetPriorityTriggerType() + XScuGic_Enable()
     *   步骤 8:   XScuTimer_* 系列 API
     *   步骤 9:   单核不需要 SGI 0
     */

    POP     {lr}
#ifdef __THUMB_INTERWORK
    BX      lr
#else
    MOV     pc, lr
#endif
```

可删除的 `.global` 声明（不再需要）：
- `enableGIC` / `enableGICProcessorInterface`
- `setPriorityMask` / `enableIntID` / `setIntPriority`
- `init_private_timer` / `start_private_timer`

**仍需保留的 `.global`**：
- `tx_irq_dispatch` — `__tx_irq_handler` 中断分发路径中仍在使用
- `disableHighVecs` — 步骤 4 中仍在使用

#### 3. 无需修改的文件

| 文件 | 说明 |
|------|------|
| `MP_GIC.S` / `MP_PrivateTimer.S` | 保留文件不删除，中断处理路径中 `readIntAck`、`writeEOI`、`clear_private_timer_irq` 仍在使用 |
| `boot.S` | 不变 |
| `board_init.c` | 不变 |
| `main.c` | 不变 |
| `lscript.ld` | 不变 |

### 五、重构后的启动流程

```
处理器复位
  └─ boot.S (_prestart/_boot)
       ├─ CPU0 门控 + eFuse 单核检测
       ├─ 无效化 Cache/TLB
       ├─ 设置各模式栈指针
       ├─ 使能 MMU + L1/L2 Cache + VFP
       └─ b _start
            └─ xil-crt0.S (_start)
                 ├─ 清零 BSS
                 ├─ 全局构造函数
                 └─ bl main
                      ├─ bsp_init()
                      │    ├─ Global_Timer_Init()
                      │    ├─ GIC_Init()
                      │    │    └─ XScuGic_CfgInitialize()  ← 覆盖原步骤 5-6
                      │    ├─ XScuGic_SetPriorityTriggerType(29, 0, 0)  ← 原步骤 7
                      │    ├─ XScuGic_Enable(29)
                      │    └─ PrivateTimer_Init()  ← 原步骤 8
                      │         └─ XScuTimer_CfgInitialize + LoadTimer + AutoReload + Start
                      ├─ board_init() (GPIO/UART/SD + 驱动注册)
                      └─ tx_kernel_enter()
                           ├─ _tx_initialize_low_level()
                           │    ├─ 切换 SVC 模式 + 保存栈指针     ← 步骤 1-2
                           │    ├─ 记录空闲内存                   ← 步骤 3
                           │    └─ 设置 VBAR + 禁用高向量         ← 步骤 4
                           ├─ tx_application_define()
                           └─ tx_thread_schedule() → AppTaskStart
```

### 六、重构优势

1. **可读性** — C 代码 + BSP API 比汇编容易理解
2. **可维护性** — BSP 驱动有参数校验，且与硬件寄存器细节解耦
3. **消除重复初始化** — 原来步骤 5-6 被 `XScuGic_CfgInitialize` 和汇编各做了一遍
4. **SMP 扩展友好** — 未来双核时 BSP API 天然支持 `Cpu_Id` 参数，`XScuGic_Enable` 会自动调用 `XScuGic_InterruptMaptoCpu` 将中断映射到指定核

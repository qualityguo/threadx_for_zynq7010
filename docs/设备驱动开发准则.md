## 驱动框架

### 设备核心层

- 关键文件

  - `device_core.h`和`device_core.c`

- 说明

  - ops：包含初始化、读、写和ioctl函数

  - 通知回调：`typedef void (*device_notify_t)(struct device *dev, uint32_t event);`

    - 用做裸机、RTOS的合并处理
    - 通过 `DEV_IOCTL_SET_NOTIFY` 命令设置，驱动在中断等场景中主动调用，通知上层事件

  - 关键API

    - ```c
      int 			device_register	(struct device *dev);
      struct device*	device_find		(const char *name);
      int				device_init		(struct device *dev);
      int 			device_read		(struct device *dev, void *buf, size_t len);
      int				device_write	(struct device *dev, const void *buf, size_t len);
      int				device_ioctl	(struct device *dev, int cmd, void *arg);
      ```

  - 返回值：成功返回 `0`，失败返回 `-1`（设备未找到、ops或函数指针为空等情况）

  - 设备注册上限：最多 `16` 个设备（`MAX_DEVICE_NUM`）

  - `struct device` 关键字段

    - `name`：设备唯一标识，用于 `device_find` 查找
    - `ops`：操作函数集，同一类驱动可共用
    - **`priv`**：驱动私有数据指针，存放硬件句柄、寄存器地址等，这是驱动开发的核心
    - `notify`：通知回调

  - `ioctl_cmd.h`

    - 不同外设的命令在不同的前8bit设置
    - 通用命令在`0x0000`到`0x00FF`
    - 当前已定义：`DEV_IOCTL_RESET`（0x0001）、`DEV_IOCTL_SET_NOTIFY`（0x0002）

  - 驱动注册在`board_init`函数中调用

### 设备驱动层

- 关键文件
  - `xxx_driver.c`
- 说明
  - 不需要头文件，只需要实现实例即可
  - 在`board_init.c`中extern实例并调用`device_register`即可

### 新增驱动开发步骤

1. 在 `ioctl_cmd.h` 中定义该外设的 ioctl 命令（前8bit区分外设类型）
2. 创建 `xxx_driver.c`，按以下顺序实现：
   - 定义 `xxx_priv` 结构体，存放该驱动的私有数据（寄存器基址、硬件句柄等）
   - 实现 `device_ops` 的四个函数（`init`/`read`/`write`/`ioctl`），不需要的置 `NULL`
   - 定义 `device_ops` 实例并赋值四个函数指针
   - 定义 `xxx_priv` 实例并初始化
   - 定义 `struct device` 全局实例，填充 `name`、`ops`、`priv`、`notify`
3. 在 `board_init.c` 中 `extern` 该 device 实例，依次调用 `device_register` 和 `device_init`

### 应用层使用

- 通过 `device_find("设备名")` 获取设备指针
- 调用 `device_read`/`device_write`/`device_ioctl` 进行操作
- 需要异步通知时，通过 `device_ioctl(dev, DEV_IOCTL_SET_NOTIFY, &callback)` 注册回调

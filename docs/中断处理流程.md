## 中断处理流程

### 情形一：初始化

- BSP的boot阶段的初始化，跳转到`main`
- `main`函数进入`_tx_initialize_low_level`
- `_tx_initialize_low_level`，初始化一些底层
  - 设置中断向量表（`__vectors`）
  - GIC初始化
  - 私有定时器初始化
  - 使能SGI

### 情形二：Tick到达

- 私有定时器计数值清0，产生IRQ
- 硬件自动保存
  - 保存当前的CPSR到SPSR寄存器
  - 保存返回地址PC到LR寄存器
  - 跳转到IRQ模式
- 跳转到中断向量表中保存的`__tx_irq_handler`
- 跳转函数`_tx_thread_context_save`（上下文保存）
- `_tx_thread_context_save`
  - 保存R0-R3寄存器到栈中（IRQ栈）
  - 读取值`_tx_thread_system_state`嵌套状态
  - 将值`_tx_thread_system_state`加1（主要是为了中断嵌套准备的，工程中不使能中断嵌套）
  - 判断`_tx_thread_current_ptr`是否是NULL（当前线程指针）
  - 非空NULL（有线程执行）
    - 保存SPSR（被中断线程的CPSR）到r2
    - LR-4，修复返回地址
    - 保存SPSR、R10、R12、LR到栈中（IRQ栈）
    - R10清0
    - 性能测试相关
      - 跳转函数`_tx_execution_isr_enter`
- 跳转函数`__tx_irq_processing_return`）（中断处理本体）
  - 保存R4-R5寄存器到栈中（IRQ栈）
  - 读取中断ID
  - 保存中断ID到r4寄存器
  - 判断是否是私有定时器的中断
  - 如果是私有定时器中断则清除中断标志，并进入`_tx_timer_interrupt`处理中断
  - `_tx_timer_interrupt`函数（tick中断具体处理）
    - `_tx_timer_system_clock++`（系统滴答计数++）
    - `_tx_timer_time_slice--`（时间片计数--），如果减到0设置标记为`_tx_timer_expired_time_slice=1`
    - 检查`_tx_timer_current_ptr`指向的定时器链表
      - 到期则，设置`_tx_timer_expired`为1
      - 没有到期则，指针前移
    - 定时器到期，执行`_tx_timer_expiration_process`
    - 时间片到期，执行`_tx_thread_time_slice`
  - GIC-EOI，通知中断处理完毕
  - 出栈R4-R5
  - 进入`_tx_thread_context_restore`
- `_tx_thread_context_restore`
  - `CPSID`，禁止IRQ
  - 新能测试相关
    - 跳转函数`_tx_execution_isr_exit`
  - `_tx_thread_system_state`减1，是否嵌套
  - 非嵌套进入`__tx_thread_not_nested_restore`
    - 非抢占
      - 出栈寄存器R0、R10、R12、LR
      - 恢复SPSR=R0
      - 出栈寄存器R0-R3
      - 恢复PC=LR
    - 抢占
      - 保存被抢占线程的栈
      - 执行调度`_tx_thread_schedule`

### 情形三：非定时器IRQ

- 前端处理和Tick类似，只不过后续跳转到`by_pass_timer_interrupt`
- 需要自己实现处理

### 情形四：主动出让调度器

- 调用sleep或者阻塞的函数

## Xilinx-FreeRTOS方案

### 第一步：汇编层处理

- 保存寄存器
- 读取中断ID，调用C语言的分发函数`vApplicationIRQHandler`
- 通知GIC
- 检查是否需要上下文切换

### 第二步：C处理

- 提取中断ID
- 调用中断处理函数

## ThreadX方案

- 思路： 

  - `by_pass_timer_interrupt`函数调用C语言的分发函数
  - 中断相关的处理依旧采用Xilinx的API
  - Tick的中断处理不需要修改

- 代码修改

  - main函数中调用GIC的初始化

    - ```c
      XScuGic xInterruptController;
      XScuGic_Config *intc_cfg;
      intc_cfg = XScuGic_LookupConfig(INTC_DEVICE_ID);
      XScuGic_CfgInitialize(&xInterruptController, intc_cfg, intc_cfg->CpuBaseAddress);
      ```

    - 主要是一个存储中断处理函数的table

  - `tx_initialize_low_level.S`函数修改`by_pass_timer_interrupt`实现

    - ```c
      by_pass_timer_interrupt:
          MOV     r0, r4
          BL		tx_irq_dispatch						// dispatch
          MOV		r0, r4
          BL      writeEOI
          POP     {r4, r5}                            // Recover preserved registers
      
          /* Jump to context restore to restore system context.  */
          B       _tx_thread_context_restore
      ```

    - ```c
      // 加入函数声明
      .global		tx_irq_dispatch
      ```

  - 实现分发函数

    - ```c
      void tx_irq_dispatch(unsigned int int_id)
      {
      	extern XScuGic xInterruptController;
      
      	if(int_id < XSCUGIC_MAX_NUM_INTR_INPUTS)
      	{
      		XScuGic_VectorTableEntry * entry =
      			&xInterruptController.Config->HandlerTable[int_id];
      		entry->Handler(entry->CallBackRef);
      	}
      }
      ```
